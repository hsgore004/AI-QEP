# Feature

User Login

## Business Goal

Allow authenticated users to access InvenTree.

## Actors

- Registered User

## Evidence

- InvenTree Login Screen
- Official InvenTree Demo Instance

## URL

https://demo.inventree.org/web/login

## UI Components

- Username field
- Password field
- Password visibility toggle
- Log In button
- Send me an email link
- Login details link

## UI Validations

- Username is mandatory
- Password is mandatory

## Workflow

1. Open the login page
2. Enter username
3. Enter password
4. Click the Log In button
