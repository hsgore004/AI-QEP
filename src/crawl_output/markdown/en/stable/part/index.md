# Parts
## Part[¶](https://docs.inventree.org/en/stable/part/#part "Permanent link")
The _Part_ is the core element of the InvenTree ecosystem. A Part object is the archetype of any stock item in your inventory. Parts are arranged in hierarchical categories which are used to organize and filter parts by function.
## Part Stock[¶](https://docs.inventree.org/en/stable/part/#part-stock "Permanent link")
Each part can have multiple [stock items](https://docs.inventree.org/en/stable/stock/) associated with it, which represent the physical quantity of that part in various locations. The total stock level for a given part is the sum of all stock items associated with that part.
### Minimum Stock[¶](https://docs.inventree.org/en/stable/part/#minimum-stock "Permanent link")
A part may have a specified "minimum stock" level. This is a user-defined value which indicates the minimum quantity of that part which should be kept in stock at all times. If the total stock level for a given part falls below the minimum stock level, the part is flagged as "low stock" and can be easily identified in the interface.
### Maximum Stock[¶](https://docs.inventree.org/en/stable/part/#maximum-stock "Permanent link")
A part may also have a specified "maximum stock" level. This is a user-defined value which indicates the maximum quantity of that part which should be kept in stock at all times. If the total stock level for a given part exceeds the maximum stock level, the part is flagged as "overstocked" and can be easily identified in the interface.
## Part Category[¶](https://docs.inventree.org/en/stable/part/#part-category "Permanent link")
Part categories are very flexible and can be easily arranged to match a particular user requirement. Each part category displays a list of all parts _under_ that given category. This means that any part belonging to a particular category, or belonging to a sub-category, will be displayed.
Each part category also shows a list of sub-categories which exist underneath it.
[ ![Part_category](https://docs.inventree.org/en/stable/assets/images/part/part_category.png) ](https://docs.inventree.org/en/stable/part/#Part_category) [ ![Part_category](https://docs.inventree.org/en/stable/assets/images/part/part_category.png) ](https://docs.inventree.org/en/stable/part/#_)
The category part list provides an overview of each part:
  * Part name and description
  * Part image thumbnail
  * Part category
  * Part stock level


The list of parts underneath a given category can be filtered by multiple user-configurable filters, which is especially useful when a large number of parts exist under a certain category.
Clicking on the part name links to the [_Part Detail_](https://docs.inventree.org/en/stable/part/views/) view.
## Part Attributes[¶](https://docs.inventree.org/en/stable/part/#part-attributes "Permanent link")
Each _Part_ defined in the database provides a number of different attributes which determine how that part can be used. Configuring these attributes for a given part will impact the available functions that can be perform on (or using) that part.
### Virtual[¶](https://docs.inventree.org/en/stable/part/#virtual "Permanent link")
A _Virtual_ part is one which does not physically exist but should still be tracked in the system. This could be a process step, machine time, software license, etc. Refer to the [virtual parts documentation](https://docs.inventree.org/en/stable/part/virtual/) for more information.
### Template[¶](https://docs.inventree.org/en/stable/part/#template "Permanent link")
A _Template_ part is one which can have _variants_ which exist underneath it. [Read further information about template parts here](https://docs.inventree.org/en/stable/part/template/).
### Assembly[¶](https://docs.inventree.org/en/stable/part/#assembly "Permanent link")
If a part is designated as an _Assembly_ it can be created (or built) from other component parts. As an example, a circuit board assembly is made using multiple electronic components, which are tracked in the system. An _Assembly_ Part has a Bill of Materials (BOM) which lists all the required sub-components. [Read further information about BOM management here](https://docs.inventree.org/en/stable/manufacturing/bom/).
### Component[¶](https://docs.inventree.org/en/stable/part/#component "Permanent link")
If a part is designated as a _Component_ it can be used as a sub-component of an _Assembly_. [Read further information about BOM management here](https://docs.inventree.org/en/stable/manufacturing/bom/)
### Testable[¶](https://docs.inventree.org/en/stable/part/#testable "Permanent link")
Testable parts can have test templates defined against the part, allowing test results to be recorded against any stock items for that part. For more information on testing, refer to the [testing documentation](https://docs.inventree.org/en/stable/part/test/).
### Trackable[¶](https://docs.inventree.org/en/stable/part/#trackable "Permanent link")
Trackable parts can be assigned batch numbers or serial numbers which uniquely identify a particular stock item. Trackable parts also provide other features (and restrictions) in the InvenTree ecosystem.
[Read further information about trackable parts here](https://docs.inventree.org/en/stable/part/trackable/).
### Purchaseable[¶](https://docs.inventree.org/en/stable/part/#purchaseable "Permanent link")
If a part is designated as _Purchaseable_ it can be purchased from external suppliers. Setting this flag allows parts be linked to supplier parts and procured via purchase orders.
#### Suppliers[¶](https://docs.inventree.org/en/stable/part/#suppliers "Permanent link")
A [Supplier](https://docs.inventree.org/en/stable/purchasing/supplier/) is an external vendor who provides goods or services.
#### Supplier Parts[¶](https://docs.inventree.org/en/stable/part/#supplier-parts "Permanent link")
Purchaseable parts can be linked to [Supplier Parts](https://docs.inventree.org/en/stable/purchasing/supplier/#supplier-parts). A supplier part represents an individual piece or unit that is procured from an external vendor.
#### Purchase Orders[¶](https://docs.inventree.org/en/stable/part/#purchase-orders "Permanent link")
A [Purchase Order](https://docs.inventree.org/en/stable/purchasing/purchase_order/) allows parts to be ordered from an external supplier.
### Salable[¶](https://docs.inventree.org/en/stable/part/#salable "Permanent link")
If a part is designated as _Salable_ it can be sold to external customers. Setting this flag allows parts to be added to sales orders.
## Locked Parts[¶](https://docs.inventree.org/en/stable/part/#locked-parts "Permanent link")
Parts can be locked to prevent them from being modified. This is useful for parts which are in production and should not be changed. The following restrictions apply to parts which are locked:
  * Locked parts cannot be deleted
  * BOM items cannot be created, edited, or deleted when they are part of a locked assembly
  * Parameters linked to a locked part cannot be created, edited or deleted


The part locking functionality can be enabled or disabled globally via the [Part Locking](https://docs.inventree.org/en/stable/settings/global/#parts) system setting (`PART_ENABLE_LOCKING`). When disabled, the locked state of a part is ignored and all operations are permitted.
## Active Parts[¶](https://docs.inventree.org/en/stable/part/#active-parts "Permanent link")
By default, all parts are _Active_. Marking a part as inactive means it is not available for many actions, but the part remains in the database. If a part becomes obsolete, it is recommended that it is marked as inactive, rather than deleting it from the database.
## Units of Measure[¶](https://docs.inventree.org/en/stable/part/#units-of-measure "Permanent link")
Each type of part can define a custom "unit of measure" which is a standardized unit which is used to track quantities for a particular part. By default, the "unit of measure" for each part is blank, which means that each part is tracked in dimensionless quantities of "pieces".

Read more on how InvenTree supports [physical units of measure](https://docs.inventree.org/en/stable/concepts/units/)
### Physical Units[¶](https://docs.inventree.org/en/stable/part/#physical-units "Permanent link")
It is possible to track parts using physical quantity values, such as _metres_ or _litres_. For example, it would make sense to track a "wire" in units of "metres":

### Supplier Part Units[¶](https://docs.inventree.org/en/stable/part/#supplier-part-units "Permanent link")
By default, units of measure for [supplier parts](https://docs.inventree.org/en/stable/purchasing/supplier/#supplier-parts) are specified in the same unit as their base part. However, supplier part units can be changed to any unit _which is compatible with the base unit_.
Example: Supplier Part Units
If the base part has a unit of `metres` then valid units for any supplier parts would include `feet`, `cm`, `inches` (etc)

## Part Images[¶](https://docs.inventree.org/en/stable/part/#part-images "Permanent link")
Each part can have an associated image, which is used for display purposes throughout the InvenTree interface. A prominent example is on the part detail page itself:

Thumbnail images are also used throughout the interface, particularly in table views, to reduce data load on the server. These thumbnail images are generated automatically when a new part image is uploaded.
### Uploading Part Image[¶](https://docs.inventree.org/en/stable/part/#uploading-part-image "Permanent link")
#### Web Interface[¶](https://docs.inventree.org/en/stable/part/#web-interface "Permanent link")
In the web interface, part images can be uploaded directly from the [part view](https://docs.inventree.org/en/stable/part/views/). Hover the mouse cursor over the Part image to reveal multiple options:

| --- | --- |  
| Upload new image  | Select an image file from your local computer to associate with the selected part  |  
| Select from existing images  | Select an image from a list of part images which already exist in the database  |  
| Delete image  | Remove the associated image from the selected part  |  
#### API[¶](https://docs.inventree.org/en/stable/part/#api "Permanent link")
Image upload is supported via the [InvenTree API](https://docs.inventree.org/en/stable/api/), allowing images to be associated with parts programmatically. Further, this means that the [Python interface](https://docs.inventree.org/en/stable/api/python/) also supports image upload.
#### Mobile App[¶](https://docs.inventree.org/en/stable/part/#mobile-app "Permanent link")
The [InvenTree mobile app](https://docs.inventree.org/en/stable/app/part/#part-image-view) allows part images to be directly uploaded, either from stored files or integrated camera.
## Part Import[¶](https://docs.inventree.org/en/stable/part/#part-import "Permanent link")
_Part_ data can be imported using the [data import wizard](https://docs.inventree.org/en/stable/concepts/data_import/). This allows part data to be imported from an external file, which can be useful for bulk importing of part data.
