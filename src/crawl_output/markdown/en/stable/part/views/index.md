# Part Views
## Part Views[¶](https://docs.inventree.org/en/stable/part/views/#part-views "Permanent link")
The Part detail view page provides a detailed view of a single part in the system. The page is divided into several sections, which are described in this document.
### Category Breadcrumb List[¶](https://docs.inventree.org/en/stable/part/views/#category-breadcrumb-list "Permanent link")
The categories of each part is displayed on the top navigation bar as show in the above screenshot. [Click here](https://docs.inventree.org/en/stable/part/#part-category) for more information about categories.
## Part Details[¶](https://docs.inventree.org/en/stable/part/views/#part-details "Permanent link")
Details provides information about the particular part. Parts details can be displayed in the header panel clicking on "Show Part Details" toggle button.
[ ![Part_Overview](https://docs.inventree.org/en/stable/assets/images/part/part_overview.png) ](https://docs.inventree.org/en/stable/part/views/#Part_Overview) [ ![Part_Overview](https://docs.inventree.org/en/stable/assets/images/part/part_overview.png) ](https://docs.inventree.org/en/stable/part/views/#_)
A Part is defined in the system by the following parameters:
**Internal Part Number (IPN)** - A special code which can be used to link a part to a numbering system. The IPN field is not required, but may be useful where a part numbering system has been defined.
**Name** - The Part name is a simple (unique) text label
**Description** - Longer form text field describing the Part
**Revision** - An optional revision code denoting the particular version for the part. Used when there are multiple revisions of the same master part object. Read [more about part revisions here](https://docs.inventree.org/en/stable/part/revision/).
**Keywords** - Optional few words to describe the part and make the part search more efficient.
**External Link** - An external URL field is provided to link to an external page. This could be useful the part has extra documentation located on an external server.
**Creation Date** - Indicates when the part was created and by which user (label on right-hand side)
**Units** - Units of measure (UoM) for this Part. The default is 'pcs'
## Part Tabs[¶](https://docs.inventree.org/en/stable/part/views/#part-tabs "Permanent link")
The Part view page organizes part data into sections, displayed as tabs. Each tab has its own function, which is described in this section.
### Variants[¶](https://docs.inventree.org/en/stable/part/views/#variants "Permanent link")
If a part is a _Template Part_ then the _Variants_ tab will be visible.
[Read about Part templates and variants](https://docs.inventree.org/en/stable/part/template/)
### Stock[¶](https://docs.inventree.org/en/stable/part/views/#stock "Permanent link")
The _Stock_ tab shows all the stock items for the selected _Part_. The user can quickly determine how many parts are in stock, where they are located, and the status of each _Stock Item_.
[ ![Part_Stock](https://docs.inventree.org/en/stable/assets/images/part/part_stock.png) ](https://docs.inventree.org/en/stable/part/views/#Part_Stock) [ ![Part_Stock](https://docs.inventree.org/en/stable/assets/images/part/part_stock.png) ](https://docs.inventree.org/en/stable/part/views/#_)
#### Functions[¶](https://docs.inventree.org/en/stable/part/views/#functions "Permanent link")
The following functions are available from the _Part Stock_ view.
##### Export[¶](https://docs.inventree.org/en/stable/part/views/#export "Permanent link")
Exports the stocktake data for the selected Part. Launches a dialog to select export options, and then downloads a file containing data for all stock items for this Part.
##### New Stock Item[¶](https://docs.inventree.org/en/stable/part/views/#new-stock-item "Permanent link")
Launches a dialog to create a new _Stock Item_ for the selected _Part_.
##### Stock Actions[¶](https://docs.inventree.org/en/stable/part/views/#stock-actions "Permanent link")
If stock items are selected in the table, stock actions are enabled via the drop-down menu.
### Allocations[¶](https://docs.inventree.org/en/stable/part/views/#allocations "Permanent link")
The _Allocated_ tab displays how many units of this part have been allocated to pending build orders and/or sales orders. This tab is only visible if the Part is a _component_ (meaning it can be used to make assemblies), or it is _salable_ (meaning it can be sold to customers).
### Bill of Materials[¶](https://docs.inventree.org/en/stable/part/views/#bill-of-materials "Permanent link")
The _BOM_ tab displays the [Bill of Materials](https://docs.inventree.org/en/stable/manufacturing/bom/) - a list of sub-components used to build an assembly. Each row in the BOM specifies a quantity of another Part which is required to build the assembly. This tab is only visible if the Part is an _assembly_ (meaning it can be build from other parts).
### Build Orders[¶](https://docs.inventree.org/en/stable/part/views/#build-orders "Permanent link")
The _Build Orders_ tab shows a list of the builds for this part. It provides a view for important build information like quantity, status, creation and completion dates.
### Used In[¶](https://docs.inventree.org/en/stable/part/views/#used-in "Permanent link")
The _Used In_ tab displays a list of other parts that this part is used to make. This tab is only visible if the Part is a _component_.
### Suppliers[¶](https://docs.inventree.org/en/stable/part/views/#suppliers "Permanent link")
The _Suppliers_ tab displays all the _Part Suppliers_ and _Part Manufacturers_ for the selected _Part_.
This tab is only visible if the _Part_ is designated as _Purchaseable_.
[ ![Part_Suppliers_and_Manufacturers](https://docs.inventree.org/en/stable/assets/images/part/part_manufacturers_suppliers.png) ](https://docs.inventree.org/en/stable/part/views/#Part_Suppliers_and_Manufacturers) [ ![Part_Suppliers_and_Manufacturers](https://docs.inventree.org/en/stable/assets/images/part/part_manufacturers_suppliers.png) ](https://docs.inventree.org/en/stable/part/views/#_)
### Purchase Orders[¶](https://docs.inventree.org/en/stable/part/views/#purchase-orders "Permanent link")
The _Part Purchase Orders_ tab lists all the Purchase Orders against the selected part.
This tab is only displayed if the part is marked as _Purchaseable_.
### Sales Orders[¶](https://docs.inventree.org/en/stable/part/views/#sales-orders "Permanent link")
The _Sales Orders_ tab shows a list of the sales orders for this part. It provides a view for important sales order information like customer, status, creation and shipment dates.
### Stock History[¶](https://docs.inventree.org/en/stable/part/views/#stock-history "Permanent link")
The _Stock History_ tab provide historical stock level information. Refer to the [stock history documentation](https://docs.inventree.org/en/stable/part/stocktake/) for further information.
### Test Templates[¶](https://docs.inventree.org/en/stable/part/views/#test-templates "Permanent link")
If a part is marked as _testable_ , the user can define tests which must be performed on any stock items which are instances of this part. [Read more about testing](https://docs.inventree.org/en/stable/part/test/).
### Related Parts[¶](https://docs.inventree.org/en/stable/part/views/#related-parts "Permanent link")
Related Part denotes a relationship between two parts, when users want to show their usage is "related" to another part or simply emphasize a link between two parts.
Related parts can be added and are shown under a table of the same name in the "Part" view:
[ ![Related_Parts_Example_View](https://docs.inventree.org/en/stable/assets/images/part/part_related.png) ](https://docs.inventree.org/en/stable/part/views/#Related_Parts_Example_View) [ ![Related_Parts_Example_View](https://docs.inventree.org/en/stable/assets/images/part/part_related.png) ](https://docs.inventree.org/en/stable/part/views/#_)
This feature can be enabled or disabled in the global part settings.
### Parameters[¶](https://docs.inventree.org/en/stable/part/views/#parameters "Permanent link")
Parts can have multiple defined parameters.
[Read about parameters](https://docs.inventree.org/en/stable/concepts/parameters/).
### Attachments[¶](https://docs.inventree.org/en/stable/part/views/#attachments "Permanent link")
The _Part Attachments_ tab displays file attachments associated with the selected _Part_. Multiple file attachments (such as datasheets) can be uploaded for each _Part_.
[Read about attachments](https://docs.inventree.org/en/stable/concepts/attachments/).
### Notes[¶](https://docs.inventree.org/en/stable/part/views/#notes "Permanent link")
A part may have notes attached, which support markdown formatting.
