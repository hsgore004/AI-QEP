# Stocktake
## Part Stocktake[¶](https://docs.inventree.org/en/stable/part/stocktake/#part-stocktake "Permanent link")
InvenTree can record the historical stock levels of parts, allowing users to view past stocktake data and generate reports based on this information.
A _Stocktake_ refers to a "snapshot" of stock levels for a particular part, at a specific point in time. Stocktake information is used for tracking a historical record of the quantity and value of part stock.
In particular, an individual _Stocktake_ record tracks the following information:
  * The date of the Stocktake event
  * A reference to the [part](https://docs.inventree.org/en/stable/part/) which is being counted
  * The total number of individual [stock items](https://docs.inventree.org/en/stable/stock/) available
  * The total stock quantity of available stock
  * The total value range of stock on hand


### Stock Items vs Stock Quantity[¶](https://docs.inventree.org/en/stable/part/stocktake/#stock-items-vs-stock-quantity "Permanent link")
_Stock Items_ refers to the number of stock entries (e.g. _"3 reels of capacitors"_). _Stock Quantity_ refers to the total cumulative stock count (e.g. _"4,560 total capacitors"_).
### Value Range of Stock on Hand[¶](https://docs.inventree.org/en/stable/part/stocktake/#value-range-of-stock-on-hand "Permanent link")
The total value range of stock on hand is calculated based on the provided pricing data. For stock items which have a recorded _cost_ (e.g. _purchase price_), this value is used. If no direct pricing information is available for a particular stock item, the price range of the part itself is used.
Value Range
Value data is provided as a _range_ of values, accounting for any variability in available pricing data.
### Display Historical Stock Data[¶](https://docs.inventree.org/en/stable/part/stocktake/#display-historical-stock-data "Permanent link")
Historical stock data for a particular part can be viewed in the _Stock History_ tab, available on the _Part_ page.
This tab displays a chart of historical stock quantity and cost data, and corresponding tabulated data:
[ ![Part_stocktake_tab](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_tab.png) ](https://docs.inventree.org/en/stable/part/stocktake/#Part_stocktake_tab) [ ![Part_stocktake_tab](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_tab.png) ](https://docs.inventree.org/en/stable/part/stocktake/#_)
If this tab is not visible, ensure that the _Enable Stock History_ [user setting](https://docs.inventree.org/en/stable/settings/user/) is enabled in the _Display Settings_ section.
[ ![Enable_stock_history_tab](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_enable_tab.png) ](https://docs.inventree.org/en/stable/part/stocktake/#Enable_stock_history_tab) [ ![Enable_stock_history_tab](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_enable_tab.png) ](https://docs.inventree.org/en/stable/part/stocktake/#_)
### Stocktake Entry Generation[¶](https://docs.inventree.org/en/stable/part/stocktake/#stocktake-entry-generation "Permanent link")
By default, stocktake entries are generated automatically at regular intervals (see [settings](https://docs.inventree.org/en/stable/part/stocktake/#stock-history-settings) below). However, users can generate a stocktake entry on demand, using the _Generate Stocktake Entry_ button in the _Stock History_ tab:
[ ![Generate_stocktake_entry](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_manual.png) ](https://docs.inventree.org/en/stable/part/stocktake/#Generate_stocktake_entry) [ ![Generate_stocktake_entry](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_manual.png) ](https://docs.inventree.org/en/stable/part/stocktake/#_)
This will schedule the generation of a new stocktake entry for the selected part, and the new entry will be visible in the stock history data once the generation process is complete.
## Stocktake Reports[¶](https://docs.inventree.org/en/stable/part/stocktake/#stocktake-reports "Permanent link")
In addition to the part stocktake entries, which are periodically generated for all parts in the database, users can also generate a stocktake _report_ , against a particular set of input parameters. Instead of generating a stocktake entry for a single part, this process generates a report which contains stocktake data for all parts which match the specified parameters.
The generated report (once completed) will be available for download as a CSV file, and will contain the stocktake entry data for all parts which match the specified parameters.
### Report Options[¶](https://docs.inventree.org/en/stable/part/stocktake/#report-options "Permanent link")
The following parameters can be specified when generating a stocktake report:  
| Parameter  | Description  |  
| --- | --- |  
| Part  | If provided, the report will only include stocktake data for the specified part, including and variant parts. If left blank, the report will include data for all parts in the database.  |  
| Category  | If provided, the report will only include stocktake data for parts which belong to the specified category, including any sub-categories. If left blank, the report will include data for all parts in the database.  |  
| Location  | If provided, the report will only include stocktake data for parts which have stock items located at the specified location, including any sub-locations. If left blank, the report will include data for all parts in the database.  |  
### Generating a Stocktake Report[¶](https://docs.inventree.org/en/stable/part/stocktake/#generating-a-stocktake-report "Permanent link")
The following methods for generating a stocktake report via the user interface are available:
#### Dashboard Widget[¶](https://docs.inventree.org/en/stable/part/stocktake/#dashboard-widget "Permanent link")
A dashboard widget is available for generating stocktake reports, which can be added to any dashboard view:
[ ![Stocktake_dashboard_widget](https://docs.inventree.org/en/stable/assets/images/part/stocktake_report_dashboard.png) ](https://docs.inventree.org/en/stable/part/stocktake/#Stocktake_dashboard_widget) [ ![Stocktake_dashboard_widget](https://docs.inventree.org/en/stable/assets/images/part/stocktake_report_dashboard.png) ](https://docs.inventree.org/en/stable/part/stocktake/#_)
Here, the user can specify the report parameters, and then click the _Generate Report_ button to generate a new stocktake report based on the specified parameters.
## Stocktake Settings[¶](https://docs.inventree.org/en/stable/part/stocktake/#stocktake-settings "Permanent link")
There are a number of configuration options available for controlling the behavior of part stocktake functionality in the [system settings view](https://docs.inventree.org/en/stable/settings/global/):  
| Name  | Description  | Default  | Units  |  
| --- | --- | --- | --- |  
| **Enable Stocktake**  | Enable functionality for recording historical stock levels and value  | `False`  |   |  
| **Exclude External Locations**  | Exclude stock items in external locations from stocktake calculations  | `False`  |   |  
| **Automatic Stocktake Period**  | Number of days between automatic stocktake recording  | `7`  | `days`  |  
| **Delete Old Stocktake Entries**  | Delete stocktake entries older than the specified number of days  | `False`  |   |  
| **Stocktake Deletion Interval**  | Stocktake entries will be deleted after specified number of days  | `365`  | `days`  |  
[ ![Stocktake_settings](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_settings.png) ](https://docs.inventree.org/en/stable/part/stocktake/#Stocktake_settings) [ ![Stocktake_settings](https://docs.inventree.org/en/stable/assets/images/part/part_stocktake_settings.png) ](https://docs.inventree.org/en/stable/part/stocktake/#_)
### Enable Stocktake[¶](https://docs.inventree.org/en/stable/part/stocktake/#enable-stocktake "Permanent link")
Enable or disable stocktake functionality. Note that by default, stocktake functionality is disabled.
### Automatic Stocktake Period[¶](https://docs.inventree.org/en/stable/part/stocktake/#automatic-stocktake-period "Permanent link")
Configure the number of days between generation of [automatic stocktake reports](https://docs.inventree.org/en/stable/part/stocktake/#automatic-stocktake). If this value is set to zero, automatic stocktake reports will not be generated.
### Delete Old Stocktake Entries[¶](https://docs.inventree.org/en/stable/part/stocktake/#delete-old-stocktake-entries "Permanent link")
If enabled, stocktake entries older than the specified number of days will be automatically deleted from the database.
### Stocktake Deletion Interval[¶](https://docs.inventree.org/en/stable/part/stocktake/#stocktake-deletion-interval "Permanent link")
Configure how many days historical stocktake records are retained in the database.
