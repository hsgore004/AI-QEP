# Pricing
## Part Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#part-pricing "Permanent link")
Pricing Support
Refer to the [Pricing Support](https://docs.inventree.org/en/stable/concepts/pricing/) documentation for more information on pricing support in InvenTree.
Pricing information can be determined from multiple sources:  
| Pricing Source  | Description  | Linked to  |  
| --- | --- | --- |  
| Internal Price  | How much a part costs to make  | [Part](https://docs.inventree.org/en/stable/part/)  |  
| Supplier Price  | The price to theoretically purchase a part from a given supplier (with price-breaks)  | [Supplier](https://docs.inventree.org/en/stable/purchasing/supplier/)  |  
| Purchase Cost  | Historical cost information for parts purchased  | [Purchase Order](https://docs.inventree.org/en/stable/purchasing/purchase_order/)  |  
| BOM Price  | Total price for an assembly (total price of all component items)  | [Part](https://docs.inventree.org/en/stable/part/)  |  
### Override Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#override-pricing "Permanent link")
In addition to caching pricing data as documented in the above table, manual pricing overrides can be specified for a particular part. Both the _minimum price_ and _maximum price_ can be specified manually, independent of the calculated values. If an manual price is specified for a part, it overrides any calculated value.
### Sale Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#sale-pricing "Permanent link")
Additionally, the following information is stored for each part, in relation to sale pricing:  
| Pricing Source  | Description  | Linked to  |  
| --- | --- | --- |  
| Sale Price  | How much a salable item is sold for (with price-breaks)  | [Part](https://docs.inventree.org/en/stable/part/)  |  
| Sale Cost  | How much an item was sold for  | [Sales Order](https://docs.inventree.org/en/stable/sales/sales_order/)  |  
## Pricing Tab[¶](https://docs.inventree.org/en/stable/part/pricing/#pricing-tab "Permanent link")
The pricing tab for a given Part provides all available pricing information for that part. It shows all price ranges and provides tools to calculate them.
The pricing tab is divided into different sections, based on the available pricing data.
Pricing Data
As not all parts have the same pricing data available, the pricing tab display may be different from one part to the next
### Pricing Overview[¶](https://docs.inventree.org/en/stable/part/pricing/#pricing-overview "Permanent link")
At the top of the pricing tab, an _Overview_ section shows a synopsis of the available pricing data:
[ ![Pricing_Overview](https://docs.inventree.org/en/stable/assets/images/part/pricing_overview.png) ](https://docs.inventree.org/en/stable/part/pricing/#Pricing_Overview) [ ![Pricing_Overview](https://docs.inventree.org/en/stable/assets/images/part/pricing_overview.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
This overview tab provides information on the _range_ of pricing data available within each category. If pricing data is not available for a given category, it is marked as _No data_.
Each price range is calculated in the [Default Currency](https://docs.inventree.org/en/stable/concepts/pricing/#default-currency), independent of the currency in which the original pricing information is stored. This is necessary for operations such as data sorting, price comparison, etc. Note that while the _overview_ information is calculated in a single currency, the original pricing information is still available in the original currency.
Price range data is [cached in the database](https://docs.inventree.org/en/stable/part/pricing/#price-data-caching) when underlying pricing information changes.
Refresh Pricing
While pricing data is [automatically updated](https://docs.inventree.org/en/stable/part/pricing/#data-updates), the user can also manually refresh the pricing calculations manually, by pressing the "Refresh" button in the overview section.
#### Overall Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#overall-pricing "Permanent link")
The _overall pricing_ range is calculated based on the minimum and maximum of available pricing data. Note that _overall pricing_ is the primary source of pricing data used in other pricing calculations (such as cumulative BOM costing, for example).
### Internal Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#internal-pricing "Permanent link")
A particular Part may have a set of _Internal Price Breaks_ which denote quantity pricing set by the user. Internal pricing is set independent of any external pricing or BOM data - it is determined entirely by the user. If a part is purchased from external suppliers, then internal pricing may well be left blank.
If desired, price breaks can be specified based on particular quantities.
[ ![Internal_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_internal.png) ](https://docs.inventree.org/en/stable/part/pricing/#Internal_Pricing) [ ![Internal_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_internal.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
#### Pricing Override[¶](https://docs.inventree.org/en/stable/part/pricing/#pricing-override "Permanent link")
If the **Internal Price Override** setting is enabled, then internal pricing data overrides any other available pricing (if present).
### Purchase History[¶](https://docs.inventree.org/en/stable/part/pricing/#purchase-history "Permanent link")
If the Part is designated as _purchaseable_ , then historical purchase cost information is displayed (and used to calculate overall pricing). Purchase history data is collected from _completed_ [purchase orders](https://docs.inventree.org/en/stable/purchasing/purchase_order/).
[ ![Purchase_History](https://docs.inventree.org/en/stable/assets/images/part/pricing_purchase_history.png) ](https://docs.inventree.org/en/stable/part/pricing/#Purchase_History) [ ![Purchase_History](https://docs.inventree.org/en/stable/assets/images/part/pricing_purchase_history.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
### Supplier Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#supplier-pricing "Permanent link")
If supplier pricing information is available, this can be also used to determine price range data.
[ ![Supplier_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_supplier.png) ](https://docs.inventree.org/en/stable/part/pricing/#Supplier_Pricing) [ ![Supplier_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_supplier.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
### BOM Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#bom-pricing "Permanent link")
If a Part is designated as an _assembly_ , then the [Bill of Materials](https://docs.inventree.org/en/stable/manufacturing/bom/) (BOM) can be used to determine the price of the assembly. The price of each component in the BOM is used to calculate the overall price of the assembly.
[ ![BOM_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_bom.png) ](https://docs.inventree.org/en/stable/part/pricing/#BOM_Pricing) [ ![BOM_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_bom.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
#### BOM Pricing Chart[¶](https://docs.inventree.org/en/stable/part/pricing/#bom-pricing-chart "Permanent link")
The BOM _Pricing Chart_ displays two separate "pie charts", with minimum and maximum price data for each item in the BOM. Note that prices are only shown for BOM items which have available pricing information.
Complete Pricing Required
If pricing data is not available for all items in the BOM, the assembly pricing will be incomplete
### Variant Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#variant-pricing "Permanent link")
For _template_ parts, the price of any _variants_ of the template is taken into account:
[ ![Variant_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_variants.png) ](https://docs.inventree.org/en/stable/part/pricing/#Variant_Pricing) [ ![Variant_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_variants.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
### Sale Pricing[¶](https://docs.inventree.org/en/stable/part/pricing/#sale-pricing_1 "Permanent link")
If the Part is designated as _Salable_ then sale price breaks are made available. These can be configured as desired by the user, to define the desired sale price at various quantities.
[ ![Sale_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_sale_price_breaks.png) ](https://docs.inventree.org/en/stable/part/pricing/#Sale_Pricing) [ ![Sale_Pricing](https://docs.inventree.org/en/stable/assets/images/part/pricing_sale_price_breaks.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
### Sale History[¶](https://docs.inventree.org/en/stable/part/pricing/#sale-history "Permanent link")
If the Part is designated as _Salable_ then historical sale cost information is available. Sale history data is collected from _completed_ [sales orders](https://docs.inventree.org/en/stable/sales/sales_order/).
[ ![Sale_History](https://docs.inventree.org/en/stable/assets/images/part/pricing_sale_history.png) ](https://docs.inventree.org/en/stable/part/pricing/#Sale_History) [ ![Sale_History](https://docs.inventree.org/en/stable/assets/images/part/pricing_sale_history.png) ](https://docs.inventree.org/en/stable/part/pricing/#_)
### Price Data Caching[¶](https://docs.inventree.org/en/stable/part/pricing/#price-data-caching "Permanent link")
Pricing calculations (and conversions) can be expensive to perform. This can make pricing data for complex Bills of Material time consuming to retrieve from the server, if not handled correctly.
For this reason, all information displayed in the [pricing overview](https://docs.inventree.org/en/stable/part/pricing/#pricing-overview) section is pre-calculated and _cached_ in the database. This ensures that when it needs to be retrieved (e.g. viewing pricing for an entire BOM) it can be accessed immediately.
Pricing data is cached in the [default currency](https://docs.inventree.org/en/stable/concepts/pricing/#default-currency), which ensures that pricing can be compared across multiple parts in a consistent format.
## Pricing Updates[¶](https://docs.inventree.org/en/stable/part/pricing/#pricing-updates "Permanent link")
If automated pricing updates are enabled, the pricing data updated _automatically_ , and will generally be up-to-date without user interaction. Pricing data is re-calculated and cached by the [background worker](https://docs.inventree.org/en/stable/settings/tasks/) in the following ways:
### Response to Data Changes[¶](https://docs.inventree.org/en/stable/part/pricing/#response-to-data-changes "Permanent link")
When underlying pricing data changes, the cached pricing data is automatically updated. This includes (but is not limited to):
  * Stock items being received against a [Purchase Order](https://docs.inventree.org/en/stable/purchasing/purchase_order/) with provided pricing
  * Stock items being sold against a [Sales Order](https://docs.inventree.org/en/stable/sales/sales_order/) with provided pricing
  * [Bills of Material](https://docs.inventree.org/en/stable/manufacturing/bom/) being created or modified, which may change the pricing of an assembly


### Periodic Updates[¶](https://docs.inventree.org/en/stable/part/pricing/#periodic-updates "Permanent link")
A periodic task runs in the background to ensure that any outdated or missing pricing data is kept up-to-date. This task runs at a scheduled regular interval, as controlled via the **Pricing Rebuild Interval** setting. The default value is 30 days, meaning that pricing data is updated at least once every 30 days. Setting this value to zero disables periodic updates.
### Manual Updates[¶](https://docs.inventree.org/en/stable/part/pricing/#manual-updates "Permanent link")
Additionally, the user can manually recalculate pricing for a given part. This can be done from the [pricing overview](https://docs.inventree.org/en/stable/part/pricing/#pricing-overview) display, by pressing the "Recalculate" button.
### Disable Automatic Updates[¶](https://docs.inventree.org/en/stable/part/pricing/#disable-automatic-updates "Permanent link")
Automatic pricing updates are enabled by default. If desired, this functionality can be disabled (via the **Auto Update Pricing** setting). If this is done, then pricing data will not be automatically updated, and the user must manually recalculate pricing data as required.
Disabling automatic pricing updates may be prudent in systems where pricing data changes frequently, but the user wants to control when the pricing data is updated. In this case, the user can manually recalculate pricing data as required.
