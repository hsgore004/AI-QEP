# Notifications
## General Notification Details[¶](https://docs.inventree.org/en/stable/part/notification/#general-notification-details "Permanent link")
Users can select to receive notifications when certain events occur.
Email Configuration Required
External notifications require correct [email configuration](https://docs.inventree.org/en/stable/start/config/#email-settings). They also need to be enabled in the settings under notifications`.
Valid Email Address
Each user must have a valid email address associated with their account to receive email notifications
Notifications are also shown in the user interface. New notifications are announced in the header.
[ ![Notification_header](https://docs.inventree.org/en/stable/assets/images/part/notification_header.png) ](https://docs.inventree.org/en/stable/part/notification/#Notification_header) [ ![Notification_header](https://docs.inventree.org/en/stable/assets/images/part/notification_header.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
They can be viewed in a flyout.
[ ![Notification_flyout](https://docs.inventree.org/en/stable/assets/images/part/notification_flyout.png) ](https://docs.inventree.org/en/stable/part/notification/#Notification_flyout) [ ![Notification_flyout](https://docs.inventree.org/en/stable/assets/images/part/notification_flyout.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
All current notifications are listed in the inbox.
[ ![Notification_inbox](https://docs.inventree.org/en/stable/assets/images/part/notification_inbox.png) ](https://docs.inventree.org/en/stable/part/notification/#Notification_inbox) [ ![Notification_inbox](https://docs.inventree.org/en/stable/assets/images/part/notification_inbox.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
All past notification are listed in the history. They can be deleted one-by-one or all at once from there.
[ ![Notification_history](https://docs.inventree.org/en/stable/assets/images/part/notification_history.png) ](https://docs.inventree.org/en/stable/part/notification/#Notification_history) [ ![Notification_history](https://docs.inventree.org/en/stable/assets/images/part/notification_history.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
## Part Notification Events[¶](https://docs.inventree.org/en/stable/part/notification/#part-notification-events "Permanent link")
### Low Stock Notification[¶](https://docs.inventree.org/en/stable/part/notification/#low-stock-notification "Permanent link")
If the _minimum stock_ threshold is set for a _Part_ , then a "low stock" notification can be generated when the stock level for that part falls below the configured level.
Any users who are subscribed to notifications for the part in question will receive a low stock notification via email.
### Build Order Notification[¶](https://docs.inventree.org/en/stable/part/notification/#build-order-notification "Permanent link")
When a new [Build Order](https://docs.inventree.org/en/stable/manufacturing/build/) is created, the InvenTree software checks to see if any of the parts required to complete the order are low on stock.
If there are any parts with low stock, a notification is generated for any users subscribed to notifications for the part being built.
## Subscribing to Notifications[¶](https://docs.inventree.org/en/stable/part/notification/#subscribing-to-notifications "Permanent link")
Users can "subscribe" to either a _Part_ or _Part Category_ , to receive notifications.
### Part[¶](https://docs.inventree.org/en/stable/part/notification/#part "Permanent link")
When subscribed to a _Part_ , a user will receive notifications when events occur which pertain to:
  * That particular part
  * Any parts which are variants of that part


If a user is subscribed to a particular part, it will be indicated as shown below:
[ ![Part_subscribed](https://docs.inventree.org/en/stable/assets/images/part/part_subscribe_on.png) ](https://docs.inventree.org/en/stable/part/notification/#Part_subscribed) [ ![Part_subscribed](https://docs.inventree.org/en/stable/assets/images/part/part_subscribe_on.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
If the user is not subscribed, the subscription icon is greyed out, as shown here:
[ ![Part_not_subscribed](https://docs.inventree.org/en/stable/assets/images/part/part_subscribe_off.png) ](https://docs.inventree.org/en/stable/part/notification/#Part_not_subscribed) [ ![Part_not_subscribed](https://docs.inventree.org/en/stable/assets/images/part/part_subscribe_off.png) ](https://docs.inventree.org/en/stable/part/notification/#_)
Clicking on this icon will toggle the subscription status for this part.
### Part Category[¶](https://docs.inventree.org/en/stable/part/notification/#part-category "Permanent link")
When subscribed to a _Part Category_ , a user will receive notifications when particular events occur which pertain to:
  * That particular category
  * Any sub-categories at lower levels
  * Any parts contained in the category
  * Any parts contained in the lower level categories


Subscribing to a part category operates in the same manner as for a part - simply click on the notification icon.
