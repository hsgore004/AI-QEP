# Creating Parts
## Part Creation[¶](https://docs.inventree.org/en/stable/part/create/#part-creation "Permanent link")
New parts can be created manually via the web interface, or imported from an external source.
To create or import a part, navigate to the _Parts_ view in the user interface, and select the _Add Parts_ dropdown menu above the parts table:
[ ![Add_parts_dropdown](https://docs.inventree.org/en/stable/assets/images/part/new_parts_dropdown.png) ](https://docs.inventree.org/en/stable/part/create/#Add_parts_dropdown) [ ![Add_parts_dropdown](https://docs.inventree.org/en/stable/assets/images/part/new_parts_dropdown.png) ](https://docs.inventree.org/en/stable/part/create/#_)
Permissions
If the user does not have "create" permission for the _Part_ permission group, the _Add Parts_ menu will not be available.
## Create Part Form[¶](https://docs.inventree.org/en/stable/part/create/#create-part-form "Permanent link")
New parts can be created manually by selecting the _Create Part_ option from the menu. A part creation form is opened as shown below:
[ ![New_part_form](https://docs.inventree.org/en/stable/assets/images/part/part_create_form.png) ](https://docs.inventree.org/en/stable/part/create/#New_part_form) [ ![New_part_form](https://docs.inventree.org/en/stable/assets/images/part/part_create_form.png) ](https://docs.inventree.org/en/stable/part/create/#_)
Fill out the required attributes and then press _Submit_ to create the new part. If there are any form errors, you must fix these before the form can be successfully submitted.
Once the form is completed, the browser window is redirected to the new part detail page.
### Initial Stock[¶](https://docs.inventree.org/en/stable/part/create/#initial-stock "Permanent link")
If the _Create Initial Stock_ setting is enabled, then an extra section is available in the part creation form to create an initial quantity of stock for the newly created part:
If this setting is enabled, the following elements are available in the form:
[ ![Initial_stock](https://docs.inventree.org/en/stable/assets/images/part/part_initial_stock.png) ](https://docs.inventree.org/en/stable/part/create/#Initial_stock) [ ![Initial_stock](https://docs.inventree.org/en/stable/assets/images/part/part_initial_stock.png) ](https://docs.inventree.org/en/stable/part/create/#_)
Checking the _Create Initial Stock_ form input then allows the creation of an initial quantity of stock for the new part.
### Supplier Options[¶](https://docs.inventree.org/en/stable/part/create/#supplier-options "Permanent link")
If the part is marked as _Purchaseable_ , the form provides some extra options to initialize the new part with manufacturer and / or supplier information:
[ ![Part_supplier_options](https://docs.inventree.org/en/stable/assets/images/part/part_create_supplier.png) ](https://docs.inventree.org/en/stable/part/create/#Part_supplier_options) [ ![Part_supplier_options](https://docs.inventree.org/en/stable/assets/images/part/part_create_supplier.png) ](https://docs.inventree.org/en/stable/part/create/#_)
If the _Add Supplier Data_ option is checked, then supplier part and manufacturer part information can be added to the newly created part:
[ ![Part_supplier_information](https://docs.inventree.org/en/stable/assets/images/part/part_new_suppliers.png) ](https://docs.inventree.org/en/stable/part/create/#Part_supplier_information) [ ![Part_supplier_information](https://docs.inventree.org/en/stable/assets/images/part/part_new_suppliers.png) ](https://docs.inventree.org/en/stable/part/create/#_)
## Import from File[¶](https://docs.inventree.org/en/stable/part/create/#import-from-file "Permanent link")
Parts can be imported from an external file, by selecting the _Import from File_ option.
This action opens the [data import wizard](https://docs.inventree.org/en/stable/concepts/data_import/), which steps the user through the process of importing parts from the selected file.
## Import from Supplier[¶](https://docs.inventree.org/en/stable/part/create/#import-from-supplier "Permanent link")
InvenTree can integrate with external suppliers and import data from them, which helps to setup your system. Currently parts, supplier parts and manufacturer parts can be created automatically.
Plugin Required
To import parts from a supplier, you must install a plugin which supports that supplier.
### Requirements[¶](https://docs.inventree.org/en/stable/part/create/#requirements "Permanent link")
  1. Install a supplier mixin plugin for you supplier
  2. Goto "Admin Center > Plugins > [The supplier plugin]" and set the supplier company setting. Some plugins may require additional settings like API tokens.


### Import a part[¶](https://docs.inventree.org/en/stable/part/create/#import-a-part "Permanent link")
New parts can be imported from the _Part Category_ view, by pressing the _Import Part_ button:
[ ![Import_part](https://docs.inventree.org/en/stable/assets/images/part/import_part.png) ](https://docs.inventree.org/en/stable/part/create/#Import_part) [ ![Import_part](https://docs.inventree.org/en/stable/assets/images/part/import_part.png) ](https://docs.inventree.org/en/stable/part/create/#_)
Then just follow the wizard to confirm the category, select the parameters and create initial stock.
[ ![Import_part_wizard](https://docs.inventree.org/en/stable/assets/images/part/import_part_wizard.png) ](https://docs.inventree.org/en/stable/part/create/#Import_part_wizard) [ ![Import_part_wizard](https://docs.inventree.org/en/stable/assets/images/part/import_part_wizard.png) ](https://docs.inventree.org/en/stable/part/create/#_)
### Import a supplier part[¶](https://docs.inventree.org/en/stable/part/create/#import-a-supplier-part "Permanent link")
If you already have the part created, you can also just import the supplier part with it's corresponding manufacturer part. Open the supplier panel for the part and use the "Import supplier part" button:
[ ![Import_supplier_part](https://docs.inventree.org/en/stable/assets/images/part/import_supplier_part.png) ](https://docs.inventree.org/en/stable/part/create/#Import_supplier_part) [ ![Import_supplier_part](https://docs.inventree.org/en/stable/assets/images/part/import_supplier_part.png) ](https://docs.inventree.org/en/stable/part/create/#_)
